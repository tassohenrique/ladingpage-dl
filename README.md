# Celso Dal Lago — Landing Page

Landing page pessoal do médico **Celso Dal Lago**, formado em Medicina pela UNIDERP (Campo Grande/MS) e atualmente em formação para se tornar radiologista.

## Sobre o projeto

Página estática de página única (`index.html`), sem dependências de build. Apresenta:

- **Hero** com foto e proposta central de trabalho.
- **Sobre** — formação e motivação para a Radiologia.
- **Trajetória** — linha do tempo da formação acadêmica.
- **Radiologia** — modalidades de exame de imagem de interesse.
- **Citação** de destaque.
- **Contato**.

## Tecnologias

- HTML5 + CSS3 (sem frameworks)
- Google Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) e [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)

## Rodando localmente

Basta abrir o arquivo `index.html` em qualquer navegador — não há passo de build.
